# Sicherheit

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version des Adapters.

## Sicherheitslücke melden

Bitte melde Sicherheitsprobleme nicht öffentlich in einem Issue. Schreibe stattdessen eine E-Mail an **git@felz.de** mit:

- einer Beschreibung des Problems
- den Schritten, mit denen man es nachstellen kann
- der betroffenen Version

Du bekommst in der Regel innerhalb von einer Woche eine Antwort. Nach der Korrektur wird das Problem in den Release-Hinweisen genannt, auf Wunsch mit deinem Namen.

## Hinweise zum Betrieb

Der Adapter liefert Dateien über den Web-Adapter von ioBroker aus und liest Bilder aus dem ioBroker-Dateispeicher. Er öffnet keinen eigenen Netzwerkzugang. Schütze den Web-Adapter wie bei jedem ioBroker, zum Beispiel durch ein Passwort oder eine Beschränkung auf dein Heimnetz.
